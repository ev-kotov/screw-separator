# scre-separator — разделитель для метизов

3D-модель разделителя **screw-separator** для модульного ящика **Inforce 06-20-18** системы **Modular Systems**. Разработана в **CATIA V5-5 R2022**.

Разделитель делит секцию на **4 части** для хранения метизов (винтов, болтов, гаек, шайб и т.п.).

---

## Состав 1й сборки

| Компонент     | Кол-во | Назначение            |
|---------------|:------:|-----------------------|
| `Stabilizer.CATPart`  | 4 шт   | Стабилизаторы         |
| `Short.CATPart`       | 1 шт   | Короткая перегородка  |
| `Long.CATPart`        | 1 шт   | Длинная перегородка   |

---

## Параметры

Модель параметрическая, основные параметры:

| Параметр              | Описание                          |
|-----------------------|-----------------------------------|
| `Thickness`           | Толщина стенок разделителя        |
| `ThicknessClearance` | Зазор по толщине (допуск на одну сторону)    |

Меняя эти параметры, можно подогнать разделитель под материал, технологию изготовления и нужную посадку в ячейке.

---

## Использование

1. Клонируйте репозиторий.
2. Откройте `*.CATProduct`.
3. Задайте значения `Thickness` и `ThicknessClearance`.
4. Обновите сборку (**Update All**).
5. Экспортируйте детали в `.STL` / `.STEP` для печати или производства.

## Пример фрезеровки из фанеры на CNC 3018, используя предпроцессор ПО  CamBam

За пример взят CNC 3018, это фрезерный станок с ЧПУ. Для изготовления разделителя из фанеры будем делать так: **CATIA → DXF → CamBam → G-код**.

### 1. Экспорт из CATIA

- Откройте деталь (`long.CATPart` и т.д.) в модуле 	**Drafting**.
- Создайте вид сверху (Top View) или проекцию, которая показывает контур детали в плоскости XY.
- Сохраните как **DXF** (рекомендуется версия AutoCAD R13 для лучшей совместимости, кстати в CATIA иногда возникают микроразрывы на стыках дуг, к примеру в CamBam их можно «сшить» - объединив линии в полилинию)

### 2. Импорт и подготовка в CamBam

- Откройте DXF-файл в CamBam.
- Выделите все геометрические элементы и выберите **Edit → Convert to Polyline**,  убедитесь, что контуры замкнуты.

### 3. Создание операции (MOP)

- Правой кнопкой мыши по рабочему полю → **Machining → Profile**.
- В свойствах операции задайте:
  - **Tool Diameter:** диаметр фрезы (например, 3.175 мм для CNC 3018).
  - **Target Depth:** отрицательное значение, равное толщине фанеры (например, -4 мм).
  - **Depth Increment:** шаг заглубления за проход. Для 3018 на фанере начните с **0.5 мм**.
  - **Cut Feedrate:** подача, обычно **300–500 мм/мин**.
- **Holding Tabs (перемычки):** включите (правый клик → **Holding Tabs → AutoCalc**), чтобы деталь не вылетела в конце резки. Для фанеры — **Square** табы.

### 4. Генерация G-кода

- Проверьте траекторию: зажмите **ALT + левая кнопка мыши** для вращения вида.
- Выделите группу **Machining** в дереве.
- Правый клик → **Generate GCode** → укажите папку и имя файла.

### 5. Важно для GRBL (CNC 3018)

- GRBL **не понимает Canned Cycles** (G81/G83). Для отверстий используйте **Spiral Mill** или **Profile** с заглублением.
- GRBL **не поддерживает смену инструмента (M6)**. При смене фрезы генерируйте **отдельные файлы G-кода** для каждого инструмента.
- Если GRBL ругается на дуги (G2/G3), включите в CamBam или постпроцессоре опцию **Arc as Lines**.

### 6. Проверка и запуск

- Откройте файл в **Candle**.
- Сделайте **«воздушный прогон»** (aircut): поднимите фрезу над заготовкой и запустите программу.
- Убедитесь, что траектория корректна и не выходит за пределы заготовки.
- Выставите ноль по Z и запускайте резку.
