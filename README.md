# scre-separator — разделитель для метизов

3D-модель разделителя **screw-separator** для модульного ящика **Inforce 06-20-18** системы **Modular Systems**. Разработана в **CATIA V5-5 R2022**.

Разделитель делит секцию на **4 части** для хранения метизов (винтов, болтов, гаек, шайб и т.п.).

---
# 3D модель

Состав одной сборки:

| Компонент     | Кол-во | Назначение            |
|---------------|:------:|-----------------------|
| `Stabilizer.CATPart`  | 4 шт   | Стабилизаторы         |
| `Short.CATPart`       | 1 шт   | Короткая перегородка  |
| `Long.CATPart`        | 1 шт   | Длинная перегородка   |

Модель параметрическая, основные параметры:

| Параметр              | Описание                          |
|-----------------------|-----------------------------------|
| `Thickness`           | Толщина стенок разделителя        |
| `ThicknessClearance` | Зазор по толщине (допуск на одну сторону)    |

Меняя эти параметры, можно подогнать разделитель под материал, технологию изготовления и нужную посадку в ячейке.

---

## Использование

1. Клонируйте репозиторий.
2. Откройте `*.CATProduct`.
3. Задайте значения `Thickness` и `ThicknessClearance`.
5. Экспортируйте детали в `.STL` / `.STEP` для печати или производства.

## Пример фрезеровки из фанеры 3 мм

За пример взят CNC 3018, это фрезерный станок с ЧПУ. 
Для изготовления разделителя из фанеры алгоритм будет такой: **CATIA → DXF → CamBam → G-код → CNC → Beer**.

### 1. Экспорт из CATIA

- Откройте деталь (`long.CATPart` и т.д.) в модуле **Drafting**.
- Создайте вид сверху (Top View) или проекцию, которая показывает контур детали в плоскости XY.
- Сохраните как **DXF**.

### 2. Импорт и подготовка в CamBam

В CamBam есть механизм — **CAM Styles**. Вы создаёте стиль в системной вкладке, и все операции могут наследовать его параметры .
- **Плюс**: не нужно применять к каждой операции вручную.
- **Минус**: если у вас разные операции для разных участков, Template может быть удобнее.
Рекомендую все параметры заводить в **CAM Styles**.

Настройки для сохранения в шаблон:

| Параметр | Значение | Примечание |
|---|---|---|
| **Post Processor** | **grbl** | Обязательно, иначе GRBL не поймёт код |
| **Target Depth** | **-3.2 … -3.3** | Сначала измерьте реальную толщину фанеры |
| **Depth Increment** | **1.0** | НЕ равно диаметру фрезы, дабы не сломать |
| **Cut Feedrate** | **400–500 мм/мин** | Для 3018 безопасный старт, поднимайте если справляется  |
| **Plunge Feedrate** | **150 мм/мин** | Медленное врезание |
| **Tool Diameter** | **3.175** | Ваша фреза |
| **Tool Number** | **1** | Любое ненулевое число, 0 = без смены инструмента  |
| **Style** | **cutout** | Для контурной резки |
| **Spindle Direction** | **CW** | Переключите панель свойств на **Advanced** |
| **Spindle Speed** | **10000** | Там же, в Advanced  |
| **Clearance Plane** | **5** | Там же, в Advanced |
